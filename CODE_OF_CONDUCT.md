# Code of conduct

Be decent. Assume good faith, keep criticism about the code, and take
disagreements to evidence rather than volume. Harassment, personal attacks, and
discriminatory remarks have no place here, in any channel this project uses.

Given what this project touches, one thing is not negotiable: **do not post other
people's identifiers** — profile ids, usernames, photos, message contents, chat
snippets — in issues, pull requests, or captures. Redact before you share. If a
bug report needs real data to be reproducible, describe the shape instead.

Report a problem by opening an issue on the repository, or contact the
maintainer ([@mithudso](https://github.com/mithudso)) directly if it should not
be public. Reports are handled at the maintainer's discretion; consequences for
violations range from a warning to a permanent ban from the project's spaces.
